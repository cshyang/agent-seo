# Writer prompt

Write a credible, commercially useful SUA article using the approved brief, research, outline, style guide, and lead-quality guardrails.

Produce one draft per model route listed in the stage packet, saved as
`drafts/draft-<route>.md` (e.g. `drafts/draft-primary.md`).

Requirements:
- Draft only.
- 1,500–2,200 words unless the brief says otherwise.
- Use Markdown.
- Include contextual internal links as Markdown links.
- Write for business owners, operations managers, office managers, and commercial decision-makers.
- Avoid generic SEO fluff.
- Do not invent statistics, client details, regulations, costs, or guarantees.
- End with a commercial CTA aligned with the brief.
