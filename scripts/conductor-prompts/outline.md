# Outline prompt

Create an SEO article outline from the approved brief and research.

Output:
- Proposed H1
- Subtitle
- Meta title
- Meta description
- H2/H3 outline
- Required internal links and where they appear
- CTA placement
- FAQ candidates
- Why this supports the target service page
- Lead-quality risk notes

Gate: reject if the outline does not support the target service page or attracts weak residential/low-budget intent.
